# 人工智能：新质生产力的核心引擎

新质生产力专题数据可视化网站（课程作业）。

- 纯前端单页站点：HTML / CSS / JavaScript，无构建步骤、无后端、离线自包含
- 12 个章节、22 种可视化：桑基图、旭日图、热力图、气泡图、蝴蝶图、雷达图、环形图、双轴柱状图、可拖拽力导向图谱、Canvas 粒子神经网络封面等
- 五级数据口径标注：公开数据 / 规划目标 / 机构预测 / 估算 / 示意值，共 25 处徽标；真实值与推算值以实线/虚线区分
- 交互：悬停查看逐项数值与口径、产业链图谱可拖拽与邻接高亮、深/浅主题一键切换

数据来源：国务院《新一代人工智能发展规划》（2017）、工业和信息化部公开表述、中国信息通信研究院、IDC《中国人工智能计算力发展评估报告》、世界知识产权组织《生成式人工智能专利态势报告》、国家知识产权局、国家互联网信息办公室备案信息、普华永道、麦肯锡、世界经济论坛《未来就业报告 2025》。

凡标注为「估算」「示意值」的数字仅用于表达趋势与量级，不作为统计数据引用。
